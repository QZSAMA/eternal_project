# 决策记录：雾子剧情迁移与逆转的奶 3D 训练场

## 决策

将当前女主游戏角色从小美迁移为雾子，并把小游戏输入改为共享的选球/发射/回头状态机。Three.js 保留为主渲染器，但只使用仓库内 vendored runtime 与程序化几何；2D Canvas 和 skip 继续作为现场可靠性 fallback。

## 选择原因

- 文案与真实角色设定保持一致，避免“朱盈畅”显示不完整或角色错配。
- E + A/D + 左键的状态机更贴近“先选球、再发射、再次 E 反转”的核心体验，也能被触屏按钮直接表达。
- 程序化训练场提供空间层次和边界反馈，不引入第三方地图、模型、贴图或运行时网络依赖。
- 三种模式共用同一套球体状态，降低 WebGL、2D、skip 路径的规则漂移风险。

## 约束

- 不新增 CDN、远程字体或在线 API。
- 不复制官方 OW 素材；仅抽象公开机制（治疗/伤害球与反转）。
- 行为变更先写失败测试，再实现并通过 Node 与静默 Chromium 回归。

## 复查触发器

- 升级 Three.js、引入新素材或改动球体规则。
- 现场设备出现 WebGL 初始化失败、触屏误触或低帧率漂移。
