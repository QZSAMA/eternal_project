# 求婚人物与文字分区

## 问题与决定

用户反馈英文挡住男生头部。核对发现正式结尾 `SHE SAID YES !!` 有独立不透明背景，而求婚页 `So… Will you marry me?` 与居中人物叠放，文字和戒指均遮挡人物。因此将求婚人物移到现有左侧槽位，在舞台右侧排列戒指、三段文字和回应按钮。

右侧使用柔和暗色渐变改善对比度，文字改为暖白色并减少发光；沿用用户确认的三段文案。保持戒指延迟显现、接受流程、结尾大标题和重启确认。

## 验证

- 先增加人物与戒指/文案/按钮的边界无重叠断言，确认旧布局失败，再修改实现。
- 58 项 Node 测试、语法与空白检查通过。
- 1280×720、844×390、390×844（低动效）静默 Chromium 布局检查通过；截图复查确认脸部无遮挡。竖屏仍为横向舞台等比缩放，建议横屏体验。
- 文案长度、人物尺寸、舞台分栏或按钮布局变化时重新执行 `tests/smoke-proposal-layout.py`。
