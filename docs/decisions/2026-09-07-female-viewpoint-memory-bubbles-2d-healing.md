# 决策：女生视角、回忆泡泡与 2D 求治疗小游戏

日期：2026-09-07

## 决策

1. 故事采用女生第一人称线性时间线，删除“再来一局 / 约出去见面”的玩家分支卡片。
2. 回忆阶段由 `memoryBubbles` 驱动自动轮播；玩家不选择回忆段落，只能点击右下角“但是…”进入求婚句。
3. 小游戏采用固定镜头 Canvas 2D，不再加载 Three.js。莫伊拉自动投掷会反弹的紫球；雾子按 X 或按钮发出“我需要治疗”，紫球转为黄球，黄球命中后回满血。
4. 保留 skip fallback，Canvas 不可用时继续主线。

## 原因

- 线性叙事更符合真实关系推进，避免让玩家替男方做决定。
- 自动照片泡泡适合用户后续替换真实照片，也减少现场误触和流程分叉。
- 2D 视觉更容易读懂、兼容性更高，且能保留莫伊拉/雾子玩法隐喻。
- 不把未授权官方图片或第三方网络资源作为运行时依赖。

## 影响

- `storyData.js` 成为新的线性剧情和回忆配置事实源。
- `Engine` 新增 `startMemoryBubbles` / `finishMemoryBubbles` 生命周期。
- `Minigame` 删除 3D 场景、选球和反转输入，仅保留 2D 治疗动作。
- 后续真实照片与角色贴图替换必须经过授权和隐私复查。
