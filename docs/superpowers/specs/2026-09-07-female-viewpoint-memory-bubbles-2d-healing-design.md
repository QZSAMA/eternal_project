# 女生视角回忆泡泡与 2D「我需要治疗」设计规格

## 目标

把当前故事改成以女主“雾子”的第一人称体验为主线：取消替男主做“再来一局/约出去”的分支选择，使用自动轮播的照片回忆泡泡表现两人逐渐喜欢彼此的过程；小游戏从 Three.js 3D 训练场改为固定镜头的 2D 玩法，玩家按一次 `X` 请求治疗，让场内紫球转为黄球并治疗雾子。

## 用户体验叙事

### 视角和语气

- 叙事主体使用“我”指代女生，男生使用“他”。
- 女生是玩家代入角色；玩家不替男生决定是否约会。
- 雾子是女主在游戏中的角色身份；莫伊拉是男主的角色和小游戏中的队友目标。
- 角色称呼仍保留完整真名“朱盈畅”，不得出现截断的“朱盈”。

### 线性故事顺序

1. 小红书笔记：`大龄游戏宅, 喜欢玩OW`。
2. 女生评论：`戳戳,🙋‍♀️`，两人开始聊天和组队。
3. 男生约女生参加守望先锋线下展览/活动。
4. 两人一起看演唱会重放、脱口秀，去 X118 逛动漫商品商场，到处寻找好吃的店。
5. 通过等待、聊天、分享和多次见面，逐渐确认彼此喜欢。
6. 2025 年 5 月 20 日男生约女生吃饭，拿出花正式告白，两人正式在一起。
7. 两人一起看电影《情书》，并在之后去了更多地方、看了更多演唱会，创造了有意义且开心的回忆。
8. 自动回忆泡泡结束后，右下角显示“但是…”按钮。
9. 点击“但是…”后暂停回忆层并显示：

   > 但是，他想继续和你创造更多回忆，所以——
   > Will you marry me?

10. 进入求婚画面；接受后停留在结尾画面，重新开始仍需显式确认。

### 回忆泡泡

- 不提供玩家选择回忆顺序。
- 回忆泡泡按配置数组顺序自动轮播，默认每张停留约 3.5 秒。
- 泡泡包含本地照片路径、日期/地点标签和一段第一人称短文案。
- 泡泡支持真实照片替换：只需修改 `storyData.js` 中的照片路径，不改引擎逻辑。
- 缺图时显示低干扰占位背景和文本，不阻塞剧情。
- 右下角“但是…”按钮在整个回忆轮播阶段可见，点击后停止定时器并进入最终文案。
- `prefers-reduced-motion` 下取消漂浮动画，仍保留轮播与点击逻辑。

## 2D 小游戏设计

### 名称和目标

名称：`我需要治疗`。

目标：雾子初始残血，观察莫伊拉不断投出的紫球；按 `X` 发出“我需要治疗”，将所有活动紫球转换为黄球，等待任意黄球碰到雾子并把血量恢复到满值。

### 角色和画面

- 固定 2D 竞技场视角，不使用 Three.js、WebGL、3D 相机或 3D 模型。
- 莫伊拉位于画面前方/中央，自动按固定节奏投掷紫球。
- 雾子位于莫伊拉后方，初始血量低于最大值，受到紫球伤害或场景压力时保持残血表现。
- 紫球沿场地边界反弹，形成可读的运动轨迹；转换后保留轨迹和速度，仅改变颜色、光晕和治疗属性。
- 角色图片使用本地贴图槽位：`assets/images/minigame/kiriko.*` 与 `assets/images/minigame/moira.*`。在用户提供授权素材前使用仓库内占位图，不添加远程图片依赖。

### 输入与状态

- `X` 或触屏“我需要治疗”按钮为唯一核心操作。
- 第一次按下 `X`：
  1. 设置 `needsHealing = true`，防止重复触发。
  2. 播放合成语音/音效并在 HUD 显示“我需要治疗”。不强制依赖外部音频文件。
  3. 将所有活动紫球原地转换为黄球，保留位置、速度、边界反弹状态。
- 黄球碰撞雾子后：
  1. 雾子血量设为最大值。
  2. 显示“收到治疗”与治疗粒子/闪光。
  3. 进入成功结束阶段并回调引擎。
- `Escape` 和“跳过”按钮继续可用，并直接走 skip fallback。
- 不再提供选球、A/D、鼠标瞄准、3D 移动或镜头控制。

### 降级策略

- 主模式和 fallback 都使用 Canvas 2D，同一套状态规则。
- Canvas 2D 不可用时保留 skip 模式，确保剧情可以继续。
- `vendor/three-r160.min.js` 可从 `index.html` 移除；本轮不再初始化 Three.js。
- 不新增 CDN、远程字体、在线 API 或运行时网络请求。

## 代码边界

### `storyData.js`

- 将 story 改为单一路径；删除 `branch` 菜单与 `first_date`/`gaming` 二选一跳转。
- 新增 `memoryBubbles` 配置数组、`memoryBubbleInterval`、`healingGame` 配置。
- 保留 `realHeroineName: "朱盈畅"`。

### `engine.js`

- 新增 `memory` 状态和自动泡泡生命周期：启动、切换、停止、缺图回退。
- 将“但是…”按钮绑定到 `finishMemoryBubbles()`，确保定时器清理且只执行一次。
- 小游戏结束后继续到回忆泡泡，而不是回到旧的游戏分支文案。

### `minigame.js`

- 移除 Three.js 初始化、3D 场景、3D 输入和选球逻辑。
- 保留 Canvas 2D 绘制、skip、结束回调和边界反弹测试基础设施。
- 实现 `requestHealing()`、`_convertPurpleOrbsToYellow()`、`_healKiriko()` 和自动投球。

### `index.html` / `style.css`

- 增加回忆泡泡层、照片/文本容器和右下角“但是…”按钮。
- 将小游戏 HUD 改为雾子血量、莫伊拉投球状态和“X 我需要治疗”按钮。
- 删除或隐藏旧的 3D 选球 HUD 与 Three.js 相关提示。

## 测试策略（TDD）

先写失败测试，再实现最小代码：

1. 故事不包含男生分支菜单；包含线下展览、演唱会重放、脱口秀、X118、2025-05-20、电影《情书》和最终英文求婚句。
2. 回忆泡泡自动创建、按间隔轮播；点击“但是…”会停止定时器并显示最终文案。
3. 2D 小游戏默认 `mode === "2d"`，不再依赖 `THREE`。
4. `requestHealing()` 只触发一次，紫球集合全部变为黄球。
5. 黄球碰撞雾子后血量恢复满并进入成功结束状态。
6. 触屏按钮触发同一 `requestHealing()`，skip fallback 仍可继续主线。
7. 姓名显示测试继续保证“朱盈畅”完整可见。

## 非目标

- 不制作可自由移动的 3D 角色或第一人称镜头。
- 不复制或在线加载官方守望先锋模型、地图、贴图、语音或 UI。
- 不让玩家选择回忆顺序，不保留旧的“再来一局/约出去”分支。
- 不在本轮加入真实照片上传后台；只提供本地路径槽位。
