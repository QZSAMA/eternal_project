# 雾子 3D 小游戏与剧情更新设计

日期：2026-09-07

## 目标

更新故事设定并重做“逆转的奶”小游戏：女主从小美改为雾子；开场小红书内容改为“大龄游戏宅, 喜欢玩OW”与“戳戳,🙋‍♀️”；结尾停留在最终画面并通过明确确认后才能重启；同时修复所有“朱盈畅”可能被截断为“朱盈”的显示问题。

## 玩法设计

小游戏保留莫伊拉“生化球”的原创抽象机制，但不复制 OW 的地图、模型、贴图或界面：

- Three.js 主模式改为近距离 3D 训练场：暗色空间、发光地面、几何掩体、训练无人机、球体拖尾和准星 HUD。
- 黄球代表治疗球，目标是治疗身后的雾子；紫球代表伤害球，目标是击破训练无人机。
- 球体可在训练场边界反弹；再次按 `E` 会让尚未结束的球反向飞回。
- 按 `E` 且场上没有可回头球时进入选球模式；`A/D` 或左右方向键在左侧黄球、右侧紫球之间切换；鼠标左键发射当前选中球。
- 触屏提供黄球/紫球选择与发射按钮、虚拟摇杆和“回头”按钮；鼠标右键与旧版兼容，但不改变当前选球状态。
- 选球状态、发射状态和回头状态通过文本 HUD 公告，键盘和触屏保持同一状态机。

## 剧情和内容

- 全部公开可见文案中的“小美”“冰墙”改为“雾子”及其支援语义；内部运行变量同步改为 `kiriko`/`ally` 语义。
- 公开可见姓名统一使用 `朱盈畅`；对话名牌和小游戏身份揭示均禁止换行或裁切。
- 故事开场明确写入：笔记“ 大龄游戏宅, 喜欢玩OW ”，评论“ 戳戳,🙋‍♀️ ”。标点按用户给出的 ASCII 逗号保留。

## 结尾重启交互

- 接受求婚后进入结尾层，最终画面持续显示，不再注册任意键/任意点击自动刷新。
- 结尾提供“重新开始”按钮；点击后打开同屏确认对话框“要重新开始我们的故事吗？”。
- 选择“重新开始”才调用 `location.reload()`；选择“先留在这里”关闭确认层并保持结尾画面。

## 降级和错误处理

- WebGL/Three.js 不可用时继续使用 Canvas 2D；Canvas 也不可用时自动 skip 并回到主线。
- 2D 模式实现同样的双球选择、发射和回头状态；视觉简化但规则一致。
- 缺失触屏控件、Pointer Events 或旧浏览器 API 时安全回退到键鼠和 skip。
- Three.js 3D 初始化失败不得阻塞主线。

## 验收标准

1. 所有剧情与 UI 文案测试确认“大龄游戏宅, 喜欢玩OW”“戳戳,🙋‍♀️”“雾子”和完整“朱盈畅”存在，且无用户可见“小美”残留。
2. 结尾测试确认最终层不会绑定任意键/任意点击重启，确认取消保持 `ended` 状态，确认同意才刷新。
3. 小游戏单元测试确认选球状态、A/D/方向键切换、左键发射选中球、E 回头和边界反弹。
4. `npm test`、`npm run check`、`git diff --check` 全部通过。
5. 静默 Chromium smoke 覆盖 `gaming` 和 `first_date` 两条路线；触屏 2D smoke 覆盖选球、发射、回头、跳过；页面无 404、外链运行时请求或异常。
